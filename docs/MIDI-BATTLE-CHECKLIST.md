# MIDI and battle checklist (hand test, ~15 minutes)

Tick a box only after **you** saw or heard it. Use Chrome or Edge on https or localhost with a real controller.

## MIDI (hardware required; none was available when this was written)
- [ ] Settings > CONNECT MIDI: the browser asks permission; after allowing, your controller is listed as "connected".
- [ ] Unplug and replug: the list shows disconnected, then connected again, without reloading.
- [ ] LEARN "Channel volume", move a fader: the table shows `CC n · ch c`; moving it now moves the on-screen volume slider and changes level.
- [ ] LEARN "Play / Pause", press a pad/button: it plays and pauses the deck once per press.
- [ ] Learn EQ low/mid/high, filter, tempo: each moves its slider and changes the sound.
- [ ] Learn "Match tempo", "Start on beat", "Align", "Ready": each does what the label says in a battle.
- [ ] Reload the page: the mapping is still there (stored in this browser).
- [ ] EXPORT MAPPING, CLEAR ALL, paste into the box, IMPORT: mapping returns.
- [ ] With the controller unplugged, keyboard and mouse still control everything.
- Not supported: jog wheel / platter input, 14-bit CC, controller LEDs, MIDI output.

## Battle
- [ ] PLAY (quick battle) or DJ BATTLE > ENTER THE ARENA shows your station left, Buddy's right, Deck B covered "OFF".
- [ ] READY with no track loaded: refused with a message.
- [ ] Load a demo track, MATCH TEMPO, READY: count-in with clicks and a 2-bar countdown, then LIVE with a timer.
- [ ] START ON BEAT: the deck starts on a bar line; the kick sits on the metronome beat.
- [ ] Volume fader to 0: your channel goes silent. LOW EQ to minimum: bass drops. Filter sweeps both ways.
- [ ] Round ends by itself; results list every category with its reason and Buddy's decisions.
- [ ] REMATCH starts clean (empty decks); MENU returns to the menu.
- [ ] Beginner / Intermediate / Expert feel different (Beginner is sloppy, off-phrase; Expert is exact).
- [ ] Thirty-Second Switch (90 s round): switch tracks in each 30 s window; objective score shows.
- [ ] BUDDY TRAINING: after a Beginner battle an approval request appears; APPROVE; the next battle changes track on the phrase.
